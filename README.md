# ReUsaCol

Sitio web para la recolección de objetos usados en Colombia.

## Descripción

ReUsaCol es una plataforma que facilita la donación de objetos usados, promoviendo el reciclaje y la reutilización para apoyar comunidades y el medio ambiente. Eslogan: "Lo que ya no usas, transforma vidas."

## Características

- Diseño elegante con colores negro (#000), dorado (#D4AF37) y blanco (#FFF).
- Tipografía Playfair Display para títulos y Roboto para texto.
- Animaciones avanzadas: Typewriter effect, AOS (Animate On Scroll), contadores animados.
- Funcionalidades: Formulario de recogida, calculadora de impacto, galería con lightbox, blog, login/register.
- Integración con WhatsApp, mapa de Google, testimonios carousel.
- Secciones inspiradas en recogemostususados.com: Aliados, cobertura, impacto.
- Innovadoras: Calculadora de CO2 ahorrado, seguimiento de donaciones (placeholder).

## Tecnologías

- HTML5
- CSS3 (con animaciones)
- JavaScript (ES6)
- Bootstrap 5
- Font Awesome
- PHP (para formulario)
- Librerías externas: Google Fonts, Lorem Picsum

## Páginas

- index.html: Página principal con secciones completas
- about.html: Información sobre nosotros
- services.html: Servicios ofrecidos
- contact.html: Información de contacto
- schedule.html: Formulario para programar recogida
- privacy.html: Política de privacidad

## Cómo ejecutar

- Abre index.html en un navegador para ver el sitio estático.
- Para el formulario PHP, usa un servidor local como XAMPP y coloca los archivos en htdocs, luego accede a http://localhost/index.html.
